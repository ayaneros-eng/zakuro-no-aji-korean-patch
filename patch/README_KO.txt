《석류의 맛 / Zakuro no Aji》 한글패치 v2.0m 공개 후보판

Windows 사용법
1. ZIP을 한 폴더에 모두 압축 해제합니다.
2. 깨끗한 일본 원본 ROM 파일을 Apply_Korean.bat 위로 끌어 놓습니다.
3. 원본과 같은 폴더에 Zakuro_no_Aji_Korean_v2.0m_ReleaseCandidate.sfc가 만들어집니다.
   Python 설치나 이전 버전 패치가 필요 없습니다.

이 ZIP의 Zakuro_original_to_v2.0m.bps는 일본 원본에서 바로 적용합니다.
기존 v2.0e/v2.0i 업데이트 패치를 먼저 적용하지 마세요.
원본은 2,097,152 bytes이며 512-byte 추가 헤더가 없어야 합니다.
원본 SHA256: 4e0a7f639c185b49abe70de16bf7ef062a316d986753c7aabd9b98e6b956d0b6
결과 SHA256: 9a447a967ccfe2cecb0485f3def940d8067dcfc35133a5cf5d6436784030657f

패치만 직접 적용할 때는 BPS 호환 패처에 위 BPS와 원본을 지정하세요.
이미 정확한 v2.0j 실행본이 있으면 extras/Zakuro_v2.0j_to_v2.0m.bps도 사용할 수 있습니다.
v2.0j SHA256: 1b11c4bc5624bf7fe1c09e5e60b9e784ca2459c89b11b71b4ed1a136d2ba3a8c
정확한 v2.0k와 v2.0l은 extras 폴더의 해당 업데이트 BPS를 사용할 수 있습니다.
v2.0k SHA256: c73ccd0406d6917441bb1fd57cbf20688ee947d221180a4371169e366c1ec470
v2.0l SHA256: 94914d1ecd44a2df0c3b54f82a8f511ee92ff906fed6e2f2ae09d8e479774bbc
Windows 동봉 실행기는 일본 원본 전용입니다.

macOS / Linux: Python 3.8 이상에서
  python3 -X utf8 apply_korean.py "일본 원본.sfc"
를 실행하세요. 같은 폴더의 BPS 파일이 필요합니다.

안전한 파일 처리
- 원본을 변경하지 않고 별도 결과를 만듭니다.
- 잘못된 원본이나 손상된 패치는 결과를 만들기 전에 거부합니다.
- 같은 이름의 다른 파일은 덮어쓰지 않습니다.
- 이미 결과가 정확하면 완료로 안내합니다.

이번 교정
- 선택지 첫 인물 이름 누락 19곳, 띄어쓰기 11곳, 어법 3곳, 줄바꿈 1곳을 교정.
- 선택지 3곳의 단어 중간 줄바꿈을 교정: 다녀온다, 수색한다, 선배에게.
- 첫 문장의 지명 ‘도로’를 원문 東京에 맞춰 ‘도쿄’로 수정.
- 저장 회차 단위 ‘回’를 ‘회’로 수정.
- 저장 장 제목 58개와 제작진 역할 21개의 번역문/글꼴 대응을 재작성.
- 달성률 표시와 기본 이름의 글꼴 대응을 명시적으로 고정.
- Windows 패처의 Python 의존성, 덮어쓰기, 손상 파일 처리 보완.

저장과 검수 범위
일반 SRAM 저장 파일은 별도 복사본으로 호환성을 검사합니다.
다른 ROM 버전의 세이브스테이트는 사용하지 마세요.
엔딩의 ‘끝’ 화면에는 정지하는 경로가 있습니다. 재시작은 에뮬레이터 리셋 뒤 메뉴에서 선택합니다.
세부 검수 범위와 남은 조건은 이 폴더의 QA_SCOPE_KO.txt를 확인하세요.
이 파일은 공개 후보판이며 모든 선택 조합과 실제 기기에서의 완주를 보증하지 않습니다.

ZIP에는 게임 ROM이 포함되어 있지 않습니다.
추가 UI 비트맵 글꼴의 고지와 라이선스는 FONT_NOTICE.txt 및 OFL-Noto.txt에 있습니다.
