# 석류의 맛 한글패치 v2.0m-E — 폰트 가독성 개선판

기존 배포판의 한글 글꼴이 읽기 어렵다는 의견을 반영해 **E형 정자체**를 적용했습니다.

이번 업데이트는 작은 화면에서도 초성·모음·받침을 구별하기 쉽도록 글자 모양을 다시 구성한 버전입니다. ‘도/드’, ‘온/은’처럼 혼동하기 쉬운 글자와 여러 줄의 본문 가독성을 우선해 조정했습니다.

본문·추가 UI용 한글 1,128칸(서로 다른 979종)을 교체했으며, 기존 v2.0m의 번역 내용과 분기·엔진 코드는 유지했습니다. 별도 작은 메뉴 그래픽과 일부 영문·기호는 기존 표시를 사용합니다.

## 다운로드·적용

[**`Zakuro_v2.0m-E_PUBLIC_PATCH.zip` 다운로드**](Zakuro_v2.0m-E_PUBLIC_PATCH.zip)을 받아 모두 압축 해제하세요.

BPS 호환 패처를 사용하는 경우 일본 원본에는 `Zakuro_Japanese_to_v2.0m-E.bps`, 기존 한글 v2.0m에는 `updates/Zakuro_v2.0m_to_v2.0m-E.bps` 중 하나만 적용합니다. Python 3.8 이상 환경에서는 동봉된 `apply_patch.py`도 사용할 수 있습니다. 이전 시험판이나 다른 버전 위에 덧붙이지 마세요.

**게임 ROM은 포함하지 않습니다.** 일본 원본은 2,097,152바이트이며 추가 512바이트 헤더가 없어야 합니다.

## 실행·피드백

Snes9x 1.63과 bsnes 115에서 본문·선택지 등을 확인했습니다. 다만 E형으로 전체 루트·엔딩을 새로 완주하거나 모든 환경을 전수 검수한 것은 아닙니다. 기존 일반 저장은 백업 후 복사본으로 사용하고, 다른 버전의 세이브스테이트는 사용하지 마세요.

읽기 어려운 글자, 빠진 획, 겹침이나 진행 문제가 보이면 **Issues에 패치 버전·실행 환경·문제 문장·선택 순서·스크린샷**을 남겨 주세요. 게임 ROM이나 개인 정보는 첨부하지 마세요. 제보해 주신 내용을 바탕으로 보완하겠습니다.

개선 의견과 비교 피드백을 보내 주셔서 감사합니다.
