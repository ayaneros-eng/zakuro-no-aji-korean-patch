# v2.0m ↔ v2.0m-E 비교 화면

모든 화면은 같은 진행 지점의 에뮬레이터 출력입니다. 왼쪽이 기존 v2.0m, 오른쪽이 v2.0m-E(E형)입니다. 게임 화면 위에 글자를 다시 그리거나 선명화하지 않았고, 원본 256×224 화면을 그대로 나란히 배치했습니다.
